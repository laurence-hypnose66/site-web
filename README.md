# Antigravity – Site Vitrine Laurence

Espace de travail et agent Antigravity dédié à la création, la maintenance et le déploiement du site web vitrine pour **Laurence**, relié à un nom de domaine géré chez **OVH**.

---

## 🎯 Objectifs du projet

1. **Création d'un site vitrine haut de gamme** :
   - Design moderne, épuré, responsive (mobile, tablette, desktop).
   - Excellente performance et accessibilité (score Lighthouse 95+).
   - Optimisation SEO naturel (balises meta, OpenGraph, JSON-LD schema.org).
   - Formulaire de contact sécurisé et conforme RGPD (mentions légales, politique de confidentialité).

2. **Liaison et déploiement avec le domaine OVH** :
   - Configuration de la Zone DNS chez OVH (enregistrements A, AAAA, CNAME).
   - Déploiement automatisé (Hébergement Web OVH / VPS ou plateforme moderne avec domaine pointé).
   - Sécurisation HTTPS automatique (certificat SSL Let's Encrypt).

---

## 🤖 Fonctionnement de l'agent Antigravity

L'agent utilise les instructions définies dans [`GEMINI.md`](GEMINI.md) et s'appuie sur 3 compétences spécialisées dans [`.agents/skills/`](.agents/skills/) :

| Compétence | Rôle |
| :--- | :--- |
| **`architecte-front`** | Conception de la maquette, design UI/UX, intégration responsive et moderne. |
| **`expert-seo-contenu`** | Rédaction des textes, hiérarchie éditoriale, balisage SEO et conformité RGPD. |
| **`devops-ovh`** | Configuration du nom de domaine chez OVH, gestion des DNS, certificat SSL et déploiement. |
